# Modelo de Negocio — Webby's Barbershop App

## Contexto: Zona Rural Pequeña

- Negocios con ingreso estimado: $8,000-12,000 MXN/mes
- Presupuesto tech realista: 5-10% del ingreso ($400-1,200 MXN/mes)
- Características: prefieren "comprar y ya", desconfían de suscripciones, costos predecibles

---

## Modelo Seleccionado: Híbrido (Pago único + Anualidad)

### Estructura de precios

| Concepto | Precio | Notas |
|----------|--------|-------|
| Desarrollo inicial | $4,000-6,000 MXN | Pago único, cubre setup completo |
| Hosting/mantenimiento anual | $1,500 MXN/año | ~$125 MXN/mes |
| Soporte incluido | $0 | Cambios menores (textos, fotos, horarios) |
| Funciones nuevas | $800-2,000 MXN c/u | Reportes, multi-sucursal, etc. |

### Por qué este modelo

1. **El barbero "compra" la app** — se siente como dueño, no como arrendatario
2. **Anualidad baja** — $125 MXN/mes es accesible para cualquier barbería
3. **Funciones nuevas separadas** — crece con el negocio sin subir la mensualidad
4. **Ingreso recurrente para ti** — cubre costos + margen de ganancia

## Comparativa con otros modelos

| Modelo | Ventaja | Desventaja | Ideal para |

## Estrategia de Ventas

### Primer contacto

1. Ofrecer demo gratuita (1 semana)
2. Mostrar cómo agenda citas desde el celular
3. Explicar: "pagás una vez, y cada año lo mínimo para que siga funcionando"

### Cierre

1. Pago inicial: $4,000-6,000 MXN (transferencia o efectivo)
2. Hosting: $1,500 MXN/año (cobrar junto con el inicial el primer año)
3. Renovación: contactar 30 días antes del vencimiento

### Retención

- Llamar cada 2 meses para preguntar si necesitan cambios
- Ofrecer 1 función nueva gratis cada 6 meses
- Mantener el hosting bajo para que no cancelen

---

## Notas

- Todos los precios en MXN
- Verificar tipo de cambio para costos en USD
- El precio de hosting puede subir si la infraestructura escala
- Considerar descuento del 10-15% por pago anual anticipado
- Incluir soporte por WhatsApp sin costo adicional (es lo esperado en zona rural)
